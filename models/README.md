# Model Checkpoints

This directory stores binary model weights and checkpoints only.

Current layout:

```text
models/
  nlf/
    nlf_l_multi.torchscript
  segmentation/
    yolo11m.pt
    sam2.1_hiera_large.pt
  smplx/
    SMPLX_NEUTRAL.npz
```

Configuration files belong under `configs/`, not here.
